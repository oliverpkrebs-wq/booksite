How the owner adds a book

This simple version uses GitHub Pages, so there is no signup service or complicated database.

  1. Open your GitHub repository for OPK Publishers Co.
  2. Upload the book's PDF into a folder named books. Create the folder if it does not exist.
  3. Open index.html and find the const BOOKS = [ section near the top of the script.
  4. Add a book entry using the example below. Change the title, description, and PDF filename.
  5. Save the change by committing it to GitHub. GitHub Pages will update the public library.

Example book entry:

{
  title: "My New Book",
  description: "A funny adventure.",
  file: "books/my-new-book.pdf"
},

Important: this simple version does not have private email/password accounts or a secure owner upload page. GitHub is where you add PDFs, and published books are visible to everyone.
